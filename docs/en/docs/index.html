Documentation

Everything Keyboard Utils does and how to use it – for piano, and for guitar, violin, viola, cello, flutes, clarinet, trumpet and saxophone. The first steps are on the main page. The app speaks English too: pick it on first start or in Settings > Language.

Installation

Download KeyboardUtils.exe and run it. It's a single file – nothing is installed or unpacked. It needs the .NET 10 Desktop Runtime (x64) and Windows 10 or 11; if .NET is missing, the app offers a download link on first start.

On first start it asks for the language (čeština / English); change it later in Settings > Language. If Windows says "Windows protected your PC", click More info and Run anyway (why?).

Updates: on start, at most once a day, the app asks GitHub for a new version.
When there is one, a New version … – update button appears at the bottom right: it downloads it, checks that it really is the file from GitHub (SHA-256 checksum), swaps the exe and restarts the app. If you have an unsaved recording, it asks first. After the restart it shows a What's new window (any time also via Help > What's new…). If the app sits in a folder it can't write to (such as Program Files), the button just opens the download page.
Turn the check off in Settings > Check for updates; check by hand with Settings > Check for updates now.

Songs

  • Open song ▾ > From a file loads .mid or .musicxml, .mxl files,
    for example an export from MuseScore. You can pick several files at once and switch between them
    (Library > Previous / Next song) or with Page Up / Page Down.
  • From File Explorer: right-click a .mid / .midi / .musicxml / .mxl > Open with > Keyboard Utils (the app adds itself there on first start).
    To open sheet music in Keyboard Utils with a double-click, choose Choose another app, Keyboard Utils and Always. If the app is already running, the file opens in it.
  • Find free sheet music… searches the Mutopia Project: over 2000 pieces, mostly classical, in the public domain or under Creative Commons licences. The chosen piece is downloaded and opened.
  • My songs folder (Library > My songs folder…: choose it there): every MIDI and MusicXML in it, subfolders included, is a playlist. The Play the songs button loads it.
  • File > Recent songs shows the last 10 opened.
  • Library: add the open song to your favorites or give it tags (separated by commas, e.g. jazz, hard, concert). The Library then has Favorite songs and a list of songs for each tag; they open as a playlist.
  • File > Save song as… saves the song as MIDI or MusicXML. A song from a file keeps its tempo (and its changes), time signature and key signature.
  • Remove song closes it. The file on disk stays.

Views

The switch at the right above the song picks what's shown:

  • Keyboard: falling notes on a keyboard. A key lights up in its part's colour when a note lands.
  • Sheet: sheet music on the piano's grand staff with the key signature. The current bar moves along in blue, sounding notes take their part's colour. Click a bar to move the song there; Ctrl + mouse wheel zooms.
  • Sheet + keyboard: both side by side; the divider can be dragged.

Other instruments have their own view in place of the keyboard, and the switch is named after it: Fingerboard for guitar and strings (see Fingerboard), Fingerings for the wind instruments (see Wind instruments).

  • Keyboard size (bottom right) changes the key width; a bigger window shows more octaves.
  • Key labels write the note name on every white key (otherwise only on C).
  • In the falling notes, drag up / down to move through the song; click a key to play it.
  • Settings > Dark mode (Ctrl + D) switches the whole app to dark colours.
  • Settings > Note names: school (c1, f♯2, C, B1 – as taught in Czech music schools; the default) or scientific (C4, F♯5). It applies everywhere: key labels, tuner, fingerings, note-reading trainer.

The key signature comes from the file; when the file has none, the app guesses it from the notes. Notes are aligned to sixteenths with one voice per staff, so triplets and fast ornaments look simplified.

Playback

  • Play / pause (Space) and Stop (Home, back to the start).
  • RW / FF wind while you hold them, faster the longer you hold (2× to 16×). FF during playback really speeds the song up, so you hear it. The ← / → arrows jump 5 s, with Shift 1 s.
  • Playback speed 25–200 %: the slider, the exact value in the box, the arrows next to it, or ↑ / ↓ by 5 %. The round arrow (R) goes back to 100 %.
  • Sound goes to the MIDI output chosen in Settings > MIDI output (the default is the Windows synthesizer). Keyboard Utils piano sounds better: a recording of a real upright piano (FreePats, free to share), downloaded once, about 45 MB. Remove it in the same menu. Other instruments use their own pack (see Instruments and packs).

Loop

Repeating a passage, such as a hard spot.

  1. Mark the passage by dragging across bars in the sheet music, or during playback with A (start = now) and B (end = now).
  2. The Loop button (L) turns it on / off.

Playback jumps back to the start at the end of the passage. The passage is shaded in the sheet music and outlined with dashes in the falling notes. In learning mode you practise just that passage, round after round.

Speeding up step by step

Get a hard spot up to tempo on its own: in the Learning mode… window tick Speed up the loop gradually (only with the loop on). Start at, say, 50 %. Each round played at 90 % or better makes the next one 5 % faster, up to full tempo; the status line says "sped up to 60 %". The speed reached stays set for the next practice too.

Metronome

The Metronome checkbox (M) adds a click on every beat, following the song's tempo and time signature, through tempo changes, slowing down and the loop. The first beat of the bar is accented. Before playback it counts in one bar; in learning mode in tempo that's the lead-in, so you come in on time.

Without a song

Under the metronome, tick Without a song: Play then starts just the metronome, even with no song open.

  • BPM: the tempo, 20–300. ↑ / ↓ change it by 5.
  • Detect (T): click in time and the app works out the tempo. Two taps are enough; it averages the last four.
  • Time signature: 2/4, 3/4, 4/4, 5/4 or 6/8. In 6/8 it clicks eighths and the BPM is the dotted quarter.
  • The arrow next to Metronome hides the options; the metronome stays on.

With stems the metronome only plays without a song (stems are audio recordings; the metronome plays through MIDI).

Parts and volume

The Parts / instruments panel on the right: a checkbox turns a part off (say, the hand you'll play yourself), the slider changes its volume.

Note input

In Settings > Note input choose where the app gets what you play:

  • MIDI: a digital piano or MIDI keys over USB. The most precise; it hears chords too.
  • Microphone (acoustic instrument): recognises the pitch from the sound – piano and other instruments (see Instruments). Before first use open Settings > Microphone and sensitivity…, stay quiet for a moment, click Measure noise and play a few notes. If the app reacts to noise, move the threshold to the right.
  • Computer sound: listens to what the computer plays (YouTube, Spotify…), without the app's own sound.
  • Clicking the on-screen keyboard: a clicked key counts as played. For trying it out without an instrument.

The Listen button (F7) turns listening on: sounding keys light up orange.

From sound the app hears one note at a time (except chord checking in learning mode) and can't recognise the lowest notes below F1.

Learning mode

Learning mode… (F5): choose what you play (say, just the right hand), the mode and the speed.

  • Wait for note: the song stops at the next note until you play it right.
  • In tempo: the song keeps going; a note counts when you play it on time (±0.25 s). The other parts can play as accompaniment.

The keys to play light up light blue; a note played right turns green, a mistake red – in the falling notes and in the sheet music.

With the microphone or computer sound, Check every note of a chord is on: a chord counts once all of it sounds. If the app doesn't hear some note, turn the option off and one right note is then enough for a chord.

At the end (or after End learning / Stop) you get a score: the percentage of right notes, wrong keys, missed notes, the time, last time's result, the best result and a chart of recent attempts. Try again (Enter) starts another attempt with the same settings.

Record my playing

In the Learning mode window tick Record my playing. With the microphone the sound is recorded, with MIDI keys or clicking the notes played (a loop is recorded whole, every round). The score then has ▶ Listen back and Save the recording (MP3, or WAV, or MIDI to Documents\Keyboard Utils\Nahrávky). An audio recording trims the silence at the start and end by itself, and is boosted when you played quietly. Computer sound isn't recorded (it would include the accompaniment). A recording is at most 30 minutes.

Practice history and the teacher's report

Every attempt in learning mode (and every round of a loop) is saved with the song. Practice > Practice history… shows a chart and a list of all attempts: date, percentage, speed, mode, parts and passage.

Hard spots

For each attempt the app remembers which bars had mistakes. From the last five attempts (newer ones count more) it picks the worst spots and joins neighbouring bars with mistakes, at most 4 bars:

  • the score after learning and the history show a line Most mistakes: bars 12–13, 27;
  • in the sheet music those bars get a red circle with the number of mistakes;
  • the Practise bars 12–13 button in the score (or the H key, or the macro action Practise the hard spot) sets a loop on them and starts learning.

Older mistakes count less and less; after five attempts without a mistake there, the mark goes away.

Report for the teacher

Practice > Report for the teacher (PDF)… turns the history into an overview of this week, the last 7 or 30 days, this month or any period: minutes and days practised, daily goals met, a chart of minutes per day and a table of songs (attempts, minutes, best and last result, speed, hard bars). At the bottom there's room for the teacher's note and signature. It's saved as a PDF – email it or print it.

Daily goal and streak

The bottom right shows how many minutes you've practised today in learning mode (e.g. Today 12 / 20 min · 🔥 3) and your streak of days in a row with the goal met. Hover over it for the last 7 days. Click the indicator to change the goal (default 20 min); 0 turns it off. Only time in learning mode counts (without pauses), free playback doesn't. The streak doesn't vanish in the morning: until today's goal is met, it counts up to yesterday.

Scales and warm-ups

Open song ▾ > Scales and warm-ups… (or in the Practice menu) creates an exercise as a song:

  • a scale up and down; for minor keys choose harmonic, melodic or natural,
  • a broken chord (arpeggio) of the tonic,
  • a chromatic scale (in semitones),
  • a T–S–D–T cadence (chords in the right hand, bass notes in the left),
  • chord inversions (root position, 1st and 2nd inversion and back),
  • Hanon No. 1: a finger warm-up up the degrees of the key.

Choose the key (12 major, 10 minor), the range of 1 or 2 octaves, the hand (right, left, both), the tempo and quarter or eighth notes. The exercise has bars and a key signature, so everything works on it as on a song: learning mode, the loop and speeding up, the metronome and the history. Save it with File > Save song as….

Note-reading trainer

Practice > Note-reading trainer… shows a note on the staff and you click its name or press the letter on the keyboard (C D E F G A B; H works too). With Microphone ticked (off by default; following your note input it may also say MIDI or Computer sound) you can also play it on your instrument – then the exact pitch and octave must match; the buttons judge only the name. After a wrong answer the right note is shown and played.

  • Levels: treble clef (c1–g2), bass clef (F–c1), both clefs, advanced (ledger lines, sharps and flats) and intervals – two notes above each other, answer with a button or the digits 2–8 (2 = second … 8 = octave).
  • A time limit of 5, 3 or 2 s per note (or none); when it runs out, it counts as a mistake.
  • A round has 20 notes; at the end you see how many were right, the average time per note, the longest run and the best result for the level.
  • Notes you get wrong come up more often – in later rounds too; at the end of the round you see which they were.

Instruments and packs

Your instruments are tabs at the top, like in a browser (e.g. Piano | Guitar | Violin). + adds another, × (or the middle mouse button) closes a tab, and you reorder them by dragging. To choose from: piano, guitar, violin, viola, cello, flute, soprano recorder, clarinet in B♭, trumpet in B♭ and alto saxophone in E♭. Switching the tab switches the instrument; the open song stays.

The piano is always in the app; the other instruments are downloadable packs (3–14 MB) with the instrument's real sound – recordings from FreePats and VSCO 2 Community Edition (Versilian Studios), both in the public domain (CC0). A pack is downloaded when you first add the instrument (a tab that still needs it has ⤓ before its name). Settings > Instruments (download, remove)… downloads several at once or deletes ones you don't need. For an instrument other than the piano:

  • instead of the keyboard there's a fingerboard (guitar, violin, viola, cello) or fingering charts (recorder, flute, clarinet, saxophone, trumpet);
  • music on a single staff in the instrument's clef: treble, guitar (with the 8 under the clef), alto, bass. Transposing instruments see the music as they read it: clarinet and trumpet a tone higher, alto saxophone a sixth – key signature included (a song in F major is in G major for the clarinet);
  • the instrument's sound in playback and when you play the fingerboard or the fingering chart – from its pack (violin, viola and cello also have pizzicato);
  • the microphone allows for the bow and the breath: notes follow without a new attack (legato) and vibrato stays one note. Notes outside the instrument's range are ignored;
  • the note-reading trainer has levels for your instrument (the beginning without accidentals and the full range with sharps and flats) plus the alto and tenor clefs. A played note is judged by how it sounds – on the clarinet you play a written D and it's right;
  • scales and warm-ups: scale, chromatic scale, broken chord and scale in thirds, single-line from the instrument's lowest tonic. Choose the key as you read it; when two octaves don't fit the range, it's one;
  • Save song as MusicXML writes the instrument's part with its clef and transposition. And the other way round: MusicXML with a transposition (a clarinet or trumpet part from MuseScore) loads at the right pitch;
  • a Tuner button right next to Listen and Learning mode.

Fingerboard: guitar and strings

The guitar (6 strings, frets 0–12) and the violin, viola and cello (4 strings, fingers for 1st position, 0 = open string) have a fingerboard instead of the keyboard. It lights up where to play: in the part's colour during playback, in learning mode blue for what to play, orange for what the app hears and red for a mistake. Rings show the notes coming up.

  • Left hand: click a fret (finger place) to "press" a string; click again to let go; × releases them all.
  • Guitar: on the right you strum by dragging the mouse across the sound hole (a click = one string, a faster drag = louder), so you can play chords too.
  • Violin, viola, cello: on the right you bow along a string – the note sounds as long as you drag; a short click is pizzicato.
  • While a song plays the strings move with it: the guitar's are plucked from the fret where the note is played, and a bowed string moves for as long as each note lasts.

Guitar: tablature and chords

  • Tablature (TAB) under the notes: fret numbers on six lines, showing which string each note is played on (top line = the thinnest string). Chord notes go on different strings and the hand stays in its position; strings written in MusicXML are kept, and saved MusicXML includes them. The fingerboard shows the notes in the same places. Turn it off in Settings > Guitar: tablature under the notes.
  • Chord symbols above the notes (C, Am, G7, F/C…): from MusicXML for any instrument, and for the guitar also guessed from the notes when the file has none (clear chords only; a melody on its own gets none). The chord sounding now is highlighted. Click a symbol to see the chord's shape and hear it. Turn it off in Settings > Chord symbols above the notes.
  • Practice > Chord library (guitar)…: the first chords a guitarist learns (C, D, E, F, G, A, Dm, Em, Am, Bm, sevenths, maj7, sus) as songbook boxes – finger numbers, × not played, ○ open string. Click one to hear it; with the guitar it's pressed and strummed on the fingerboard.

Wind instruments

The recorder, flute, clarinet, alto saxophone and trumpet have the instrument drawn across the whole panel instead of the keyboard: the recorder with its head, window and double holes (the thumb hole is at the back, so it's drawn under it), the flute with its keys, levers and foot joint, the black clarinet with silver rings, the brass saxophone with key cups and pearl touches, the trumpet with its valves. The small keys (thumb, register, octave, palm, little-finger and side keys) are under the instrument with their names. On the left is the name of the note you play (in learning mode, the one to play), big, and its fingering lights up on the instrument. Click the name to hear the note.

Falling bars

Above each hole and key is its lane (the thumb and the levers have theirs too), and the song falls down the lanes like the falling notes onto the keyboard:

  • a bar lands on the line above the instrument = cover the hole (press the key, the valve),
  • the bar ends = lift the finger; the bar's length = how long to hold,
  • when a finger stays down over several notes, the bar continues; a repeated note has a small gap,
  • a half-covered hole (pinched thumb, one of the double holes) has a half-width bar,
  • left of the lanes are the names of the notes coming; you see 3 s ahead, so you see the tempo too.

Play with the mouse

  • A click covers a hole / presses a key or valve. On the recorder the thumb and the double holes go covered → half → open.
  • Your fingers light up orange, green where they match the note; a blue ring = cover this hole too.
  • Hold Blow to hear the fingering's note – in learning mode it counts as played. Harder: the flute an octave up (overblowing), the trumpet's next partial. A fingering that isn't in the chart is reported.
  • × release fingers goes back to showing the note's fingering.

Fingerings

  • Recorder (soprano): written c1–d3 (sounds an octave higher), baroque (default) or German fingering – Settings > Recorder fingering. They differ on F, F♯, G♯ and B♭.
  • Flute: the basic fingerings of the Boehm flute, c1–a3; the same fingering an octave up is overblown.
  • Trumpet in B♭: valves for written f♯ – c3; the same valves play several notes, the embouchure picks (Blow / Harder).
  • Clarinet in B♭: written e – c3; from b1 up, the register key (thumb) and the fingering a twelfth lower.
  • Alto saxophone in E♭: written b♭ – f3; from d2 the octave key and the fingering an octave lower, at the top the palm keys.
  • The flute, clarinet and saxophone fingerings are the basic fingerings of the Woodwind Fingering Guide.

Tuner

Practice > Tuner… (or the Tuner button, the Tuner macro action) listens to the microphone and shows the note, a needle from −50 to +50 cents (green when in tune – within ±5 cents), the frequency and, for transposing instruments, the written note. For the guitar, violin, viola and cello it shows the strings and lights up the one you're tuning (even when it's far off), with the advice tighten / loosen. Click a string to hear it. The a1 reference can be set to 430–446 Hz (orchestras often use 442). The tuner sits beside the window, so you can tune and play straight away.

Writing down notes

Write notes (F6): play and the app writes down what it hears. After Stop recording the recording opens as a song. Play it back, and if you like it, save it with the Save button (next to Write notes) as:

  • MIDI: exactly what you played,
  • MusicXML for MuseScore: notes aligned to sixteenths on the grand staff. The app asks for the tempo of the notation; set it to roughly what you played at.

Ctrl + R saves the recording straight away as MIDI to Documents\Keyboard Utils\Nahrávky, without a dialog.

Editing a recording

Before you save a recording you can fix wrong notes in the falling notes – no need to play it again:

  • Select: a click selects a note, Shift + click adds / removes another, dragging across empty space selects several.
  • Move: drag the selected notes with the mouse, or move them with ← / → (by 20 ms).
  • Pitch: ↑ / ↓ by a semitone.
  • Delete: Delete.
  • Exactly: a double-click on a note opens its pitch, start and length in milliseconds.
  • Undo / redo: Ctrl + Z / Ctrl + Y.

Only a fresh, unsaved recording can be edited. Saving it or opening another song ends the editing.

Stems and turning audio into notes

Import stems… offers two options:

  • As accompaniment: choose a folder of stems (.wav) and the original recording plays; each stem can be turned off or down. The Notes button on a stem detects its notes and shows them alongside the recording. Then turn the stem off and play it yourself with the original, in learning mode too.
  • Detect notes from music: turns an audio file (WAV, MP3, FLAC, AIFF) into notes as a new song.

Stems from FL Studio: Export > WAV File > Miscellaneous > "Split mixer tracks". Links to stems of finished songs are right in the dialog.

Add-on: chord detection

Without the add-on, the conversion hears one note at a time. An optional add-on, the Basic Pitch neural network from Spotify (about 5 MB), recognises chords too. The app offers it on the first conversion; download or remove it any time in Settings > Chord detection (add-on)….

With stems, playback and learning in tempo run at 100 % only: the original recording can't be slowed down.

Macro keyboard

A second keyboard (a programmable one such as SayoDevice, an old keyboard, a numeric keypad…) can control the app, so you can run all of it without the computer keyboard and mouse – your hands stay at the instrument. Its keys don't reach Windows; the main keyboard types normally.

Setting it up

  1. Edit > Macro keyboard… > Set up macro keyboard… The first time, the app downloads a small module. If the Interception driver is missing, it offers to install it (administrator rights) and restart the computer.
  2. Press a key on the keyboard you want to use and confirm with Use this keyboard.
  3. Add key…, press a key on the macro keyboard and pick an action.

Actions

  • Playback: play / pause, stop, move by 5 or 1 s, volume of all parts.
  • Metronome: on / off, without a song, tempo detection, next time signature.
  • Loop and speed: loop, start, end, slower / faster / 100 %.
  • Songs: next / previous, my songs folder, recent songs, open song.
  • Learning and recording: learning mode and its settings without the dialog (wait / in tempo, what you play, speed), practice history, write notes, save the recording, listen, note input.
  • View: switch the view, note and keyboard size, key labels, dark mode, window to the front / minimise.
  • Dialogs and windows: Enter, Esc, Tab, arrows and Space, so you can answer every dialog in the app (e.g. the score: Enter = try again, Esc = close).
  • Parts of the song: turn each part off / on and its volume ±10 %.
  • Note: play a chosen note.

Knob

A rotary knob on a macro keyboard sends one key over and over as it turns. Pick a stepping action (move, speed, volume, note size, next song, arrows…) and leave Knob: turn it the other way to set the opposite direction ticked; then just turn the knob the other way. Fast turning adds up into one step (5 clicks = a 25 s move); when moving through songs, only the one you stop on is loaded.

Big messages: what a macro key or shortcut did shows for a moment in big letters in the middle of the window, readable from the instrument. Turn them off in Settings > Big messages.

Save the key assignments with Export… and load them with Import…. Controls on temporarily turns capturing off; the macro keyboard then types normally.

Interception is a kernel-level driver; anti-cheats such as Vanguard (Valorant) or FACEIT may block it. Uninstall it by hand with install-interception.exe /uninstall (as administrator) and a restart.

Sheet music from Muzio

A teacher can attach a piece's sheet music (MIDI or MusicXML) to an assignment in Muzio. Click Open in Keyboard Utils on the assignment: the app starts (or comes to the front if it's running) with that piece. The first time, the browser asks whether it may open Keyboard Utils – allow it. Practise the piece, slowed down, in a loop or in learning mode. Once you can play it, record the assignment in Muzio as usual.

If nothing happens after the click, you don't have Keyboard Utils 1.1 or newer (or haven't run it yet – it registers the links on first start). Then download the file by clicking its name and open it with Open song ▾ > From a file. Sheet music from Muzio is saved to %LOCALAPPDATA%\KeyboardUtils\Muzio; the app downloads only MIDI and MusicXML from Muzio's storage, at most 5 MB.

The Muzio menu in the app: Muzio… says what Muzio is and opens it in the browser. If you don't use Muzio, hide the menu with Hide the Muzio menu; Settings > Show the Muzio menu brings it back.

Settings and data

  • Settings: %APPDATA%\KeyboardUtils\config.json
  • Practice history: %APPDATA%\KeyboardUtils\history.json
  • Add-ons (macro keyboard, chords, piano sound): %APPDATA%\KeyboardUtils\modules
  • Instrument packs: %APPDATA%\KeyboardUtils\instruments
  • Recordings saved without a dialog: Documents\Keyboard Utils\Nahrávky

The app only goes online to GitHub (updates, add-ons, instrument packs), to the Mutopia Project when you search for sheet music, and to Muzio when you open sheet music from it. It sends nothing about you.

Troubleshooting

  • Windows won't run the app: see Why Windows says it "protected your PC".
  • No sound: check Settings > MIDI output and the parts' volume in the panel on the right.
  • The microphone doesn't react, or reacts to noise: Settings > Microphone and sensitivity…, measure the noise and move the threshold.
  • The new version doesn't show: close all Keyboard Utils windows and start it again.
  • An instrument won't download: check your internet connection and try again by clicking its tab or in Settings > Instruments (download, remove)…. The app checks a downloaded pack; a damaged one isn't used.
  • The macro keyboard stopped working after re-plugging USB: Interception has 10 keyboard slots; after many unplugs a computer restart helps.

Found a bug or missing something? Write it on GitHub, or, if you don't have GitHub, send it here (in the app: Help > Report a bug…).
