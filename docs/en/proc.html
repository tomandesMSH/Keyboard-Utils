Why does Windows
"protect your PC"
from Keyboard Utils?

In short: Keyboard Utils isn't signed with a paid certificate, and not enough people have downloaded it yet for Windows to "know" it. It's not that Windows found anything dangerous in it.


The longer version:

What Windows SmartScreen is

The message comes from Microsoft Defender SmartScreen, a protection built into Windows. When you run a program downloaded from the internet, SmartScreen looks at two things:

  • The signature. Is the program digitally signed by a publisher someone has verified?
  • The reputation. How many people have already downloaded and run the same file without trouble?

When both are missing, Windows would rather stop and ask you. So the message doesn't mean "this is a virus" but "I don't know this program". It does the same for lots of small programs by individuals, schools...

Why the app isn't signed

A code-signing certificate costs a few hundred euros a year and is issued after an identity check. Keyboard Utils is free – I'd like it to stay free – and one person works on it in their spare time, which is why it isn't signed. SmartScreen's reputation also starts from zero with every new version, so the message may pop up for later updates too, until Windows gets "used to" the app.

How to check you have the real app

  • Download only with the button on this site or from the GitHub page. Both lead to the same file from the official repository (the online folder that holds the app's source code).
  • The source code is all public on GitHub. Anyone can read what the app does.
  • For complete peace of mind, upload the downloaded file to VirusTotal. It checks it with dozens of antivirus programs at once.

What the app does on your computer

  • It installs nothing. It's one file that runs straight away; delete it and it's gone.
  • Settings and practice history are saved in %APPDATA%\KeyboardUtils.
  • On the internet it only talks to GitHub – to check for new versions (once a day, can be turned off) and to download optional add-ons and instrument packs. When you search for free sheet music it connects to the Mutopia Project. No information about you is collected.
  • Administrator rights are asked for only once, when you set up a macro keyboard yourself and install its driver. Without a macro keyboard it never needs them.

How to run it

  1. Run the downloaded KeyboardUtils.exe.
  2. In the "Windows protected your PC" window, click More info.
  3. Check that App says KeyboardUtils.exe and click Run anyway.

Windows remembers this and won't ask next time.
